# OA-ARDM
_Based on a Google Research_ [_paper_](https://arxiv.org/pdf/2110.02037)

Implementation of Order-Agnostic Autoregressive Diffusion Models (OA-ARDMs)
applied to two modalities: binarized **MNIST** (images) and the fully
categorical **UCI Mushroom** dataset.

## Layout

```
model/
  model_components.py          image input parametrization f(i,m,t)
  models.py                    LeNetWithTime, TinyTimeViT
  train_OA_ARDMs.py            Algorithms 1 (sampling) & 2 (training) — images
  model_components_tabular.py  tabular input parametrization
  models_tabular.py            MLPWithTime, TabTransformer
  train_OA_ARDMs_tabular.py    Algorithms 1 & 2 — tabular
utils/
  config.py                    hyperparameters
  utils.py                     sinusoidal time embedding, categorical helper
  tabular_data.py              Mushroom loader/encoder + marginal-TVD metric
tests/
  test_tabular_ardm.py         unit tests for the tabular pipeline
main_mnist.py                  trains LeNet/ViT on MNIST  -> results/  (reproduces report)
main_tabular.py                trains MLP/Transformer on Mushroom -> results/
make_figures.py                builds the report figures from results/ -> figs/
main.py                        original minimal MNIST runner
```

## Setup

```
pip install -r requirements.txt
```

Requires PyTorch (CUDA optional). MNIST downloads automatically on first run;
Mushroom is fetched via `ucimlrepo`.

## Reproduce the report

```
python main_tabular.py     # Mushroom: train/val/test bpd + sample fidelity
python main_mnist.py       # MNIST: train/val/test bpd + digit samples
python make_figures.py     # writes figures into figs/
python -m pytest tests/    # unit tests (pip install pytest)
```

`results/`, `figs/` and `data/` are generated by the commands above and are not
shipped with this folder.
